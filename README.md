A one-line resignation letter, generated deterministically by `main.ts`.

Run it:

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes a single line (129 characters, no trailing newline) to `out/entry.txt`:

> I resign, effective immediately: the office plant got promoted twice while I watered it, and I refuse to take orders from a fern.
